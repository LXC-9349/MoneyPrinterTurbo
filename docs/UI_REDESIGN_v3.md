## 0. 一句话结论

界面**功能能跑**,但**"不好管理"是真实的**:导航层信息架构没统一(生成/作品/任务三处职责重叠、标题重复)、
i18n 约定破了(侧栏英文界面下露出中文与 `menu` 裸标签)、作品卡片**大面积为空**(封面/时长/大小缺失)、
且**文案承诺了不存在的功能**(重命名)。以下逐条给证据 + 方案。

## 2. 方案(建议)

### 2.1 信息架构:导航分三组 + 去重标题

```
───────────  创作
🎬 生成视频      (Generate)      ← 主入口,普通模式置顶为默认
───────────  作品
📁 我的作品      (Projects)      ← 作品库,唯一"管理成片"入口
───────────  系统
📋 任务运行      (Tasks)         ← 只保留"运行/失败监控",去掉与 Projects 重复的成片操作
🗂️ 存储管理      (Storage)
📚 资料库        (Library)
👤 人物          (Persons)
```

- 侧栏:分组标题 + `label_visibility="collapsed"` 去掉裸 `menu`;标题走 i18n。
- **单一返回入口**:只在顶部栏保留"← 生成视频"(或面包屑),删掉页内重复按钮。
- 管理页 **banner 只保留标题**,删掉每页重复的 `admin_page_hint` 无信息提示。

### 2.2 Projects 作品管理(重点做实)

| 项 | 方案 |
|---|------|
| 封面 | ① 列表渲染时对缺失封面的作品**惰性补抽首帧**(ffmpeg -ss 1)并回写索引;② 抽帧失败用统一占位图 |
| 回填 | 一次性**迁移**:对已有 project 补 `aspect/duration/size/thumbnail/source/tags` 快照 |
| 重命名 | 真正实现:`title` 可编辑(st.text_input + 保存),详情页与卡片都支持 |
| 脏数据 | 修入库源(标题优先取 `params.video_subject`,过滤 `download...` 之类按钮文本);清理现有脏条目 |
| 排序 | 加排序选择(时间/标题/时长/大小) |
| 批量 | 多选 + 批量删除/批量导出(可选,放 P1) |
| 分组 | 用已有 `mode`/`person` 做快速筛选 chip(替代当前两个下拉),`tags` 落库 |

### 2.3 Generate 生成页

- 默认 **normal 模式**;传记作为并列 tab/模式,不进默认首屏。
- 四栏 → **分步/分组**(创意→脚本→画面→声音→生成),或至少把 audio 的 37 控件折叠为"基础/高级"。
- 保留现有全部控件与逻辑(**不删功能**),只重组展示层级。

### 2.4 i18n 一致性巡检

- 把 §1-F 的硬编码中文调用点改为 `t("key")`(key 已存在,直接替换)。
- 加一条测试:静态扫描 webui/*.py,禁止直接写入中文字面量(纳入 i18n 套件)。

### 2.5 视觉(在现有 styles.css 上增强,不换框架)

- 沿用 Streamlit + 现有 `styles.css` 扩展:统一卡片圆角/阴影/间距 token、导航分组样式、空状态、骨架屏。
- **不引入新前端框架**(保持 Streamlit,零后端破坏)。
